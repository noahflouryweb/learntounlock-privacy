# Règles de confidentialité — LearnToUnlock

Dernière mise à jour : 18 novembre 2026. Éditeur : Noah Floury. Contact : learntounlock.apps@gmail.com

LearnToUnlock ne demande aucun compte et n'affiche aucune publicité.

Données sur ton téléphone uniquement : ta progression, tes listes, tes réglages et la liste des applis verrouillées sont enregistrés sur ton téléphone. Ils ne sont envoyés à personne. Désinstaller l'appli les efface.

Accès aux données d'utilisation : l'appli s'en sert seulement pour savoir quelle appli est ouverte, afin d'afficher les exercices quand une appli verrouillée s'ouvre. Cette information reste sur le téléphone.

Superposition et notification : utilisées pour afficher l'écran d'exercices et signaler que le blocage est actif.

Traduction dans l'appli : elle utilise ML Kit de Google, qui traduit sur le téléphone. Le texte traduit n'est pas envoyé à Google. ML Kit télécharge le modèle de langue et envoie à Google des informations techniques (modèle du téléphone, version d'Android et de l'appli, langues choisies, mesures de performances, identifiant d'installation) pour le diagnostic. Plus d'infos : https://developers.google.com/ml-kit/android-data-disclosure

Bouton « Traduire la phrase » avec Google Traduction : s'il est utilisé, la phrase est envoyée à Google Traduction, selon les règles de Google (https://policies.google.com/privacy).

Dictionnaire : si tu l'acceptes, l'appli le télécharge une seule fois depuis GitHub (learntounlock.github.io), puis l'utilise hors ligne. Aucune donnée personnelle n'est envoyée ; comme pour toute page web, GitHub voit l'adresse IP du téléphone.

Partage de listes : uniquement quand tu le décides, via le menu Partager d'Android.

Génération par IA (option) : si tu la configures, le texte de ta demande est envoyé au serveur indiqué dans les réglages, seulement pour créer la liste demandée.

Enfants : l'appli ne s'adresse pas aux moins de 13 ans.

Questions ou demande : écris à learntounlock.apps@gmail.com.
